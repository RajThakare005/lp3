PRACTICAL 14 - CREATE YOUR OWN WALLET USING METAMASK FOR CRYPTO TRANSACTIONS
===============================================================================

AIM
Create a MetaMask wallet and understand its use for blockchain/crypto transactions.

WHAT IS A CRYPTO WALLET?
A crypto wallet manages the cryptographic keys that let a user access blockchain
accounts and authorize transactions. The wallet does not literally store coins;
the blockchain records balances and transactions.

WALLET CREATION STEPS
1. Visit https://metamask.io/ and install the official browser extension.
2. Open MetaMask and choose the option to create a new wallet.
3. Review the wallet setup and privacy prompts.
4. Choose a secure unlock method offered by the current MetaMask setup flow.
5. If using a Secret Recovery Phrase, carefully write it down and store it offline.
6. Confirm the recovery phrase if the setup process asks you to.
7. Set a strong password for unlocking the wallet on that device.
8. After setup, open the wallet and copy the public account address when needed.
9. Switch to a test network for lab exercises and use test ETH.
10. Before approving any transaction, verify the network, recipient, value and fee.

IMPORTANT WALLET TERMS
- Public address: an account identifier that can be shared to receive assets.
- Private key: secret cryptographic key used to authorize transactions.
- Secret Recovery Phrase: recovery material used to restore access to the wallet.
- Password: unlocks the wallet locally; it is not a replacement for the recovery phrase.
- Transaction: a signed request that changes blockchain state or transfers assets.
- dApp: decentralized application that interacts with a blockchain.

SECURITY PRECAUTIONS
- Never share the Secret Recovery Phrase or private key.
- Do not enter recovery words into websites, forms or chat messages.
- Install MetaMask only from its official website and linked browser-store listing.
- Check the website URL before connecting the wallet.
- Read every transaction request before confirming it.
- Use a separate practice wallet and test ETH for college demonstrations.
- Never send real ETH to a testnet address or test ETH to a mainnet address expecting
  it to have real-world value.

RESULT
A MetaMask wallet was created and its public address, private-key security and
transaction-signing purpose were studied.
